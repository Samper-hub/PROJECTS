BuscadorEnParalelo is a multi-process Java console application designed to locate and count keyword occurrences across multiple .txt files simultaneously using ProcessBuilder. Built incrementally through object-oriented inheritance without overwriting previous versions, the architecture demonstrates operating system process management, inter-process communication, and concurrency control. In the base implementation (Gestor and Buscador), a coordinator process scans a target directory and spawns an independent child process per text file, collecting results from standard output into informe.txt while routing error streams to errores.log. The first enhancement (Gestor1 and Buscador1) extends the base classes to capture per-process execution telemetry, including total lines processed, OS Process ID (PID), and execution duration. The second enhancement (Gestor2) introduces dynamic concurrency control capped at a maximum of 4 active processes at any time, immediately dispatching the next queued file as soon as an active process finishes rather than waiting for static batches. The project also includes a comprehensive unit test plan covering nominal executions and edge-case error handling such as invalid paths, missing parameters, and unreadable files.
